1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

    Git: ветка - это ссылка на коммит. Никаких файлов не копируется. Поэтому дёшево.
    SVN: ветка - это папка репозитория. Чтобы её создать, сервер делает копию структуры проекта. Поэтому дорого.

2. Можно ли в SVN сделать коммит без интернета? Почему?
    Без связи с сервером svn commit завершится ошибкой.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

    Если в проекте есть фольшие файлы по типу фидео или игр.
