# Сравнение Git и SVN

**1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?**
- Git: ветка = указатель на коммит (40 байт), создаётся за секунду
- SVN: ветка = копия всех файлов, требует много места и времени

**2. Можно ли в SVN сделать коммит без интернета?**
- Нет. SVN — централизованная система, коммит идёт на сервер

**3. Когда SVN лучше Git?**
- Legacy-проекты (госсектор, банки)
- Контроль доступа к папкам
- Огромные бинарные файлы
